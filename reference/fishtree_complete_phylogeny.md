# Get complete (stochastically-resolved) phylogenies from the Fish Tree of Life

Retrieves a complete phylogeny generated by stochastic polytomy
resolution via the Fish Tree of Life API. If neither \`species\` nor
\`taxon\` are specified, returns the entire phylogeny. See Rabosky et
al. (2018) and Chang et al. (2019) for details on how these phylogenies
were built using stochastic polytomy resolution. WARNING: These
phylogenies should generally not be used for downstream analyses of
trait evolution. See Rabosky (2015) for details.

## Usage

``` r
fishtree_complete_phylogeny(
  species,
  taxon,
  mc.cores = getOption("mc.cores", 1L),
  release = getOption("fishtree.release", .default_release),
  rank = deprecated()
)
```

## Arguments

- species:

  (Optionally) subset the results based on a vector of species names.

- taxon:

  (Optionally) subset the results to the taxon with this name, such as a
  family or order (e.g., \`"Acanthuridae"\`).

- mc.cores:

  Number of cores to use in
  [mclapply](https://rdrr.io/r/parallel/mclapply.html) when subsetting
  the tree (default \`1\`)

- release:

  The tree release to use, from
  [`fishtree_releases`](https://fishtree.fishtreeoflife.org/reference/fishtree_releases.md).
  Defaults to \`getOption("fishtree.release")\`, or \`"R2018"\` if that
  is unset. Looking up a \`taxon\` is only available for \`"R2018"\`.

- rank:

  Deprecated; use \`taxon\` instead.

## Value

An object of class \`"multiPhylo"\` that should probably not be used for
analyses of trait evolution, including (but not limited to)
[pic](https://rdrr.io/pkg/ape/man/pic.html),
[ace](https://rdrr.io/pkg/ape/man/ace.html),
[corBrownian](https://rdrr.io/pkg/ape/man/corBrownian.html),
[make.bisse](https://rdrr.io/pkg/diversitree/man/make.bisse.html), or
[hisse](https://rdrr.io/pkg/hisse/man/hisse.html).

## Examples

``` r
if (FALSE) { # \dontrun{
tree <- fishtree_complete_phylogeny(taxon = "Acanthuridae")
sampled_tips <- fishtree_phylogeny(taxon = "Acanthuridae")$tip.label
all_tips <- tree[[1]]$tip.label
new_tips <- setdiff(all_tips, sampled_tips)
par(mfrow = c(2,2))
for (ii in 1:4) {
  plot(tree[[ii]], show.tip.label = FALSE, no.margin = TRUE)
  ape::tiplabels(pch = 19, col = ifelse(tree[[ii]]$tip.label %in% new_tips, "red", NA))
}
} # }
```
